JavaJam Coffee House ☕

Project Overview

JavaJam Coffee House is a front-end web development project created as part of my Computer Science coursework at Umm Al-Qura University.

The project focuses on building a coffee house website using HTML5, CSS3, and JavaScript, combining structured web pages, visual styling, and interactive functionality.

Features

* Multi-Page Navigation: Links between the website’s pages, including Home and Menu.
* Responsive User Interaction: JavaScript-based alerts and prompts.
* Welcome Message: Prompts visitors for their names and displays a personalized greeting.
* Discount Notification: Displays a promotional discount code.
* Geolocation: Uses the browser’s Geolocation API to request the user’s location, with permission and error handling.
* Website Styling: Uses CSS for page layout, typography, backgrounds, and navigation.

Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Geolocation API
* Visual Studio Code

Skills Demonstrated
